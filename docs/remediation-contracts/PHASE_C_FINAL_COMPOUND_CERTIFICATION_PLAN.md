**Status:** FROZEN CLOSURE REQUIREMENT
**Scope:** final multi-edge synthesis after 163/163 edge classification

## 1. Purpose

Pairwise Phase C classifications are necessary but not sufficient for final closure. The final synthesis must prove that multi-node authority, identity, evidence, and historical-lineage invariants survive composition across complete governed paths.

The mandatory hard-chain certification target is:

`R4 → R9 → R10 → R17 → R19 → R20`

This is a genuine six-node worked certification scenario. It must not be satisfied by restating the five pairwise edge outcomes.

## 2. Canonical six-node scenario

The fixture must establish one exact historical path:

1. R4 freezes Evaluation Cycle A and the exact authority that justifies the governed Build/Factory path.
2. R9 freezes Build Source Snapshot S1 under Cycle A, preserving exact immutable source identity and originating R4 lineage.
3. R10 creates Artifact Version P1 from exact source S1 and preserves immutable artifact/build provenance.
4. R17 freezes Offer Version O1 and the exact `CUSTOMER_CHARGING` Grant G1 that govern the commercial action associated with P1.
5. R19 creates complete immutable Commercial Authority Lineage L1 binding the exact R4/R9/R10/R17 segments and any other required lineage dimensions.
6. R20 performs a fresh boundary-time decision against exact L1 and every current predicate without replacing any historical segment with current state.

The affirmative control case passes only when every segment is exact, internally consistent, and currently eligible where R20 requires current eligibility.

## 3. Required divergence matrix

The same base scenario must then inject one deliberate mismatch at a time while all other segments remain valid.

### D1 — R4 divergence
Cycle B becomes current after S1 was frozen under Cycle A. Any later reconstruction that substitutes B for A must fail chain integrity. Current Opportunity membership or semantic similarity cannot reconcile the mismatch.

### D2 — R9 divergence
R9 source identity changes from S1 to S2 while downstream artifact/lineage still claims the historical S1 path. Current repository HEAD, branch membership, or mutable source references cannot substitute.

### D3 — R10 divergence
Artifact P2 derived from S2 is substituted into a lineage whose source segment remains S1. A valid R4/R9 prefix does not repair an R10 artifact mismatch.

### D4 — R17 divergence
Offer O2 or Grant G2 becomes current after O1/G1 were frozen. L1 must continue to bind O1/G1. Current price, current Offer, `commercialActive`, or present monetization configuration cannot substitute.

### D5 — R19 divergence
The complete lineage object claims individually valid upstream segments that are not mutually equal to the historical path that actually produced the action. R19 must fail closed rather than selecting whichever segment is current or independently valid.

### D6 — R20 boundary divergence
L1 remains historically perfect, but a current R20 predicate becomes ineligible, stale, revoked, paused, denied, or otherwise invalid. Historical chain correctness must not become perpetual execution authority.

## 4. Cross-segment attacks

The final fixture must also test failures that no single adjacent edge owns by itself:

1. **mixed-current reconstruction:** several historical segments are silently replaced by mutually consistent current successors, producing a coherent but wrong chain;
2. **partial historical substitution:** only one skip-link or composite field points to a later generation while adjacent references remain individually valid;
3. **same-parent laundering:** mismatched objects share the same Opportunity/Product/Asset parent and are incorrectly treated as interchangeable;
4. **duplicate-field equality drift:** where a composite structure legitimately carries separately first-class identity fields, two copies diverge while each independently resolves;
5. **mediator reachability without equality:** the system can navigate from a downstream object to some upstream object but not prove it is the exact one carried by the mediator;
6. **historical-valid/current-invalid:** every immutable historical segment is correct but present boundary authority is invalid;
7. **current-valid/historical-wrong:** a fully valid current successor chain exists but must not repair or replace the historical chain being evaluated.

## 6. Pass condition

The six-node hard-chain synthesis passes only if:

1. the affirmative A/S1/P1/O1-G1/L1 scenario reaches R20 without historical identity substitution;
2. every single-link divergence D1-D6 fails at the correct owning boundary without laundering the mismatch elsewhere;
3. cross-segment attacks fail even when all pairwise objects are individually valid in isolation;
4. no current successor object can repair a historical mismatch;
5. no historical-valid chain can bypass a failing current R20 predicate;
6. every failure preserves the original historical records rather than mutating them into a coherent story;
7. the result is consistent with every relevant pairwise Phase C classification and does not silently contradict an open defect or unresolved gap.
