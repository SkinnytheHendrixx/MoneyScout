## 2. Governing distinction

I1 keeps three claims separate:

1. **historical exact-name provenance** — whether the original frozen source proves the literal name;
2. **current recovered-contract vocabulary** — whether the present recovered contract itself normatively uses a label to express the recovered semantics;
3. **future implementation naming authority** — whether implementation/remediation may encode that label once implementation authority is restored.

A label can be normative recovered-contract vocabulary while still not being historically source-confirmed. Likewise, recovered-contract vocabulary is not yet implementation enum authority while implementation authority remains suspended.
